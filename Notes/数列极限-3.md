# 数学分析：实数完备性与数列收敛

> [!abstract] 课堂概要
> 本节课围绕实数完备性展开，重点讲解了**单调有界原理**、**致密性定理**（Bolzano-Weierstrass定理）和**柯西收敛准则**，并通过多个典型例题演示了这些定理的应用。老师指出，实数完备性共有6个相互等价的定理，这些定理是刻画实数完备性的基石。

---

## 一、 单调有界原理

### 1. 定理陈述
单调有界数列必收敛。具体分为两种情况：
1. 若数列 $\{a_n\}$ 单调递增且有上界，则 $\lim_{n\to\infty} a_n = \sup\{a_n \mid n=1,2,\dots\}$。
2. 若数列 $\{a_n\}$ 单调递减且有下界，则 $\lim_{n\to\infty} a_n = \inf\{a_n \mid n=1,2,\dots\}$。

> [!note] 与确界原理的等价性
> 该定理与确界原理是等价的。课堂上利用**确界原理**证明了单调递增有上界的情形，而单调递减的情形留作练习。反过来，也可以利用单调有界原理去证明确界原理。

### 2. 证明过程（基于确界原理）
**证明单调递增有上界的情况：**
由确界原理，存在实数 $\xi \in \mathbb{R}$，使得 $\xi = \sup\{a_n\}$。下证 $\lim_{n\to\infty} a_n = \xi$。
$\forall \epsilon > 0$，因为 $\xi - \epsilon$ 不再是 $\{a_n\}$ 的上界，故 $\exists n_0 \in \mathbb{N}^*$，使得：
$$ \xi - \epsilon < a_{n_0} $$
又因为 $\xi$ 是 $\{a_n\}$ 的上界，且 $\{a_n\}$ 单调递增，所以 $\forall n > n_0$，有：
$$ \xi - \epsilon < a_{n_0} \le a_n \le \xi < \xi + \epsilon $$
从而 $|a_n - \xi| < \epsilon$，即 $\lim_{n\to\infty} a_n = \xi$。 $\square$

## 二、 单调有界原理的应用例题

### 例题 1：证明 $S_n = \sum_{k=1}^n \frac{1}{k^2}$ 收敛

**思路：** 显然 $S_n$ 单调递增，只需证明有上界。
利用放缩法，当 $k \ge 2$ 时：
$$ \frac{1}{k^2} < \frac{1}{k(k-1)} = \frac{1}{k-1} - \frac{1}{k} $$
因此：
$$ S_n = 1 + \sum_{k=2}^n \frac{1}{k^2} < 1 + \sum_{k=2}^n \left( \frac{1}{k-1} - \frac{1}{k} \right) = 1 + \left( 1 - \frac{1}{n} \right) < 2 $$
由单调有界原理，$S_n$ 收敛。

> [!tip] 扩展与思考
> 该级数的极限为 $\lim_{n\to\infty} \sum_{k=1}^n \frac{1}{k^2} = \frac{\pi^2}{6}$（巴塞尔问题，由欧拉最先提出）。
> 思考：如果将平方换成任意 $\alpha > 1$，即 $\sum_{k=1}^n \frac{1}{k^\alpha}$ 是否收敛？这涉及到后续的数项级数理论（$p$-级数）。

### 例题 2：递推数列 $a_n = \sqrt{2 + a_{n-1}}$（$n$重根号）

已知 $a_1 = \sqrt{2}$，$a_n = \sqrt{2 + a_{n-1}}$，证明 $\{a_n\}$ 收敛并求极限。
**步骤：**
1. **单调性**：考察 $a_n - a_{n-1}$。
   $$ a_n - a_{n-1} = \sqrt{2+a_{n-1}} - \sqrt{2+a_{n-2}} = \frac{a_{n-1} - a_{n-2}}{\sqrt{2+a_{n-1}} + \sqrt{2+a_{n-2}}} $$
   分子分母同号，可知 $a_n - a_{n-1}$ 与 $a_{n-1} - a_{n-2}$ 同号，进而与 $a_2 - a_1$ 同号。
   而 $a_2 - a_1 = \sqrt{2+\sqrt{2}} - \sqrt{2} > 0$，故 $\{a_n\}$ 单调递增。
2. **有界性**：利用数学归纳法证明 $a_n < 2$。
   显然 $a_1 = \sqrt{2} < 2$。假设 $a_n < 2$，则 $a_{n+1} = \sqrt{2+a_n} < \sqrt{2+2} = 2$。
3. **求极限**：设 $\lim_{n\to\infty} a_n = A$。对递推式两边取极限，得 $A = \sqrt{2+A}$，解得 $A = 2$（负根舍去）。

### 例题 3：递推数列 $X_n = X_{n-1} + \ln(a - X_{n-1})$
已知 $X_1 = \ln a$，$a > 1$，$X_n = \sum_{k=1}^{n-1} \ln(a - X_k)$，证明 $X_n$ 收敛并求极限。
**分析：** 记 $X_n = f(X_{n-1})$，其中 $f(x) = x + \ln(a - x)$。
求导得 $f'(x) = 1 - \frac{1}{a-x} = \frac{a-x-1}{a-x}$。
- 当 $x < a-1$ 时，$f'(x) > 0$，$f(x)$ 单调递增；
- 当 $x > a-1$ 时，$f'(x) < 0$，$f(x)$ 单调递减。
因此 $f(x)$ 在 $x = a-1$ 处取得最大值 $f(a-1) = a-1$。所以 $X_n \le a-1$，说明有上界。
又因为 $X_n - X_{n-1} = \ln(a - X_{n-1}) \ge \ln(a - (a-1)) = \ln 1 = 0$，所以 $\{X_n\}$ 单调递增。
由单调有界原理，$X_n$ 收敛。两边取极限得 $A = A + \ln(a-A) \implies \ln(a-A) = 0 \implies A = a-1$。

> [!question] 课堂练习
> 设 $X_1 = 2022$，$X_{n+1}^2 - 2X_{n+1}X_n + 2022 \ge 0$（$n \ge 1$），证明 $\{X_n\}$ 收敛并求极限。
> （思路提示：可将原式视为关于 $X_{n+1}$ 的二次不等式，结合判别式 $\Delta \ge 0$ 寻找不等关系，或尝试因式分解放缩。）

## 三、 致密性定理（Bolzano-Weierstrass 定理）

> [!important] 定理
> **有界数列必有收敛的子列。**

### 证明思路
利用单调有界原理，只要证明有界数列必存在单调子列。
设 $\{a_n\}$ 有界。考察平移子列 $\{a_{k+n}\}$（表示去掉前 $k$ 项后的数列）。
分两种情况讨论：
1. **情况一：对任意 $k \in \mathbb{N}^*$，$\{a_{k+n}\}$ 都有最大项。**
   记 $k=1$ 时的最大项为 $a_{n_1}$；$k=n_1$ 时的最大项为 $a_{n_2}$；$k=n_2$ 时的最大项为 $a_{n_3}$，以此类推。
   由于每次选取的子列范围不断缩小，得到的子列 $\{a_{n_k}\}$ 满足 $a_{n_1} \ge a_{n_2} \ge a_{n_3} \ge \cdots$，为单调递减数列，故收敛。
2. **情况二：存在某个 $k_0 \in \mathbb{N}^*$，使得 $\{a_{k_0+n}\}$ 无最大项。**
   在 $\{a_{k_0+n}\}$ 中任取第一项 $b_1 = a_{k_0+1}$。由于无最大项，必可找到 $b_2 = a_{k_0+n_1} > b_1$；同理找到 $b_3 > b_2$，如此无限进行下去，得到单调递增子列 $\{b_n\}$。
   
综合两种情况，定理得证。$\square$

## 四、 柯西（Cauchy）收敛准则

### 1. 柯西列的定义
数列 $\{a_n\}$ 称为柯西列，若 $\forall \epsilon > 0, \exists N \in \mathbb{N}^*, \forall m,n > N$，有：
$$ |a_n - a_m| < \epsilon $$

> [!info] 与数列收敛定义的对比
> 数列收敛定义：$\forall \epsilon > 0, \exists N, \forall n > N, |a_n - A| < \epsilon$。
> 柯西列定义中不涉及具体的极限值 $A$，仅利用数列自身的项来刻画。这使得在处理未知极限的数列时具有巨大优势。

### 2. 柯西收敛准则
> [!important] 定理
> **数列 $\{a_n\}$ 收敛的充要条件是 $\{a_n\}$ 为柯西列。**

### 3. 证明过程

#### (1) 必要性（收敛 $\implies$ 柯西列）
设 $\lim_{n\to\infty} a_n = A$。
$\forall \epsilon > 0, \exists N \in \mathbb{N}^*$，当 $k > N$ 时，有 $|a_k - A| < \frac{\epsilon}{2}$。
对 $\forall m, n > N$，由三角不等式：
$$ |a_n - a_m| \le |a_n - A| + |a_m - A| < \frac{\epsilon}{2} + \frac{\epsilon}{2} = \epsilon $$
故 $\{a_n\}$ 为柯西列。

#### (2) 充分性（柯西列 $\implies$ 收敛）
- **第一步：证明柯西列有界。**
  取 $\epsilon = 1$，则 $\exists N_1 \in \mathbb{N}^*$，$\forall m, n > N_1$，有 $|a_m - a_n| < 1$。
  取 $n = N_1 + 1 > N_1$，则有 $|a_m - a_{N_1+1}| < 1 \implies |a_m| < |a_{N_1+1}| + 1$。
  令 $M = \max\{|a_1|, |a_2|, \dots, |a_{N_1}|, |a_{N_1+1}| + 1\}$，则 $\forall n \in \mathbb{N}^*$，有 $|a_n| \le M$。即有界。
- **第二步：利用致密性定理找到收敛子列。**
  由 $\{a_n\}$ 有界，由致密性定理，存在收敛子列 $\{a_{n_k}\}$，设 $\lim_{k\to\infty} a_{n_k} = A$。
- **第三步：证明原数列也收敛于 $A$。**
  由于 $\{a_n\}$ 是柯西列，$\forall \epsilon > 0, \exists N \in \mathbb{N}^*$，当 $m, n > N$ 时，$|a_n - a_m| < \epsilon$。
  因为 $n_k \to \infty$（当 $k \to \infty$），对于上述 $N$，$\exists K$，当 $k > K$ 时，$n_k > N$。
  取 $m = n_k$（其中 $n_k > N$），则有 $|a_n - a_{n_k}| < \epsilon$。
  对上式两端关于 $k$ 取极限，由于 $|a_n - a_{n_k}| < \epsilon$ 对 $k$ 恒成立，令 $k \to \infty$，得：
  $$ |a_n - A| \le \epsilon $$
  因此 $\lim_{n\to\infty} a_n = A$。$\square$
