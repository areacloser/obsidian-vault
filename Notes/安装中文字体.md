安装中文字体及等宽字体，兼顾美观与开发。

---

## 一、中文字体

```bash
sudo pacman -S noto-fonts-cjk noto-fonts-emoji \
    ttf-sarasa-gothic wqy-microhei \
    adobe-source-han-sans-cn-fonts \
    adobe-source-han-serif-cn-fonts
```

| 字体 | 用途 |
|---|---|
| Noto Sans/Serif CJK | Google 泛中日韩字体，覆盖面广 |
| Sarasa Gothic（更纱黑体） | 等宽中文字体，终端/代码优先 |
| WenQuanYi Micro Hei | 经典中文黑体 |
| Source Han Sans/Serif | Adobe 思源黑体/宋体 |

---

## 二、Nerd Font（等宽+图标）

```bash
yay -S nerd-fonts-caskaydia-mono
```

| 字体 | 用途 |
|---|---|
| CaskaydiaMono Nerd Font | [[Alacritty 终端]]、[[Vim 编辑器配置]]、GTK 默认 |
| LXGW WenKai Mono | [[Waybar 状态栏]]、[[Fuzzel 启动器]]、[[Mako 通知守护进程]] |

Nerd Font 包含 Powerline 符号和图标字体，是 [[Powerlevel10k]] 正常运行的前提。

---

## 三、刷新字体缓存

```bash
fc-cache -fv
```
