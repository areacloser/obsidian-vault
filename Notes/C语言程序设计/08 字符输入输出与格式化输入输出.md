# 08 字符输入输出与格式化输入输出

> [!abstract] 课程范围
> 吴俊军老师《第03章 格式化输入与输出》PDF 第 4–22 页，§3.1 字符输入与输出、§3.2 格式化输入与输出。
> 辅助参考：《C Primer Plus》第 6 版第 4、8 章；ISO C11/C17 标准规则。以下标准辨析和 Linux 实践为补充，并非老师另行指定的考试范围。
> 前置：[[03 基本数据类型与数据表示]]、[[04 常量、变量与初始化]]、[[05 运算符与表达式]]、[[07 类型转换与混合运算]]。

## 1. 输入输出的本质

课件第 4 页用 `short a; scanf("%hd", &a); a*=2; printf("%hd", a);` 展示了输入、运算、输出三个环节。输入 `123` 时，输入流中是字符 `'1'`、`'2'`、`'3'`，而不是二进制整数 123。

```mermaid
flowchart LR
    A[输入字符序列 123] -->|scanf 读取并转换| B[short 数值 123]
    B -->|CPU 计算| C[short 数值 246]
    C -->|printf 格式化| D[输出字符序列 246]
```

- 输入：从流中取得字符，再根据需要转换为内部表示。
- 输出：将内部表示转换成指定的字符序列，再写入流。
- `stdin`：标准输入流；`stdout`：标准输出流；`stderr`：标准错误流。
- `#include <stdio.h>` 提供本章四个函数的声明。

> [!note] 标准辨析
> 标准流不等于键盘与屏幕。Linux 中它们可以连接终端、普通文件或管道。终端的规范模式（canonical mode）通常按行交付输入；C 库也可能进行缓冲，两者是不同层次。按 Enter 才能读到数据不是 `getchar` 或 `scanf` 的语言规则。

## 2. 字符输入：getchar

```c
int getchar(void);
```

从 `stdin` 读取下一个字符，成功时返回作为 `unsigned char` 解释再转换为 `int` 的字符值；读到文件结尾或发生读取错误时返回 `EOF`。

课件第 7 页例 3.1（保留其正常输入下的写法）：

```c
#include <stdio.h>
int main(void) {
    char c1, c2, c3;
    c1 = getchar();
    c2 = getchar();
    c3 = getchar();
    printf("%c%c%c", c1, c2, c3);
    printf("\n%d %d %d", c1, c2, c3);
    return 0;
}
```

假设 ASCII 环境，依次输入 `a`、Enter、`b`、Enter。输入流字符序列为 `a\nb\n`。

| 调用 | 读取字符 | ASCII 值 | 剩余输入 |
|---|---|---:|---|
| 第一次 | `a` | 97 | `\nb\n` |
| 第二次 | `\n` | 10 | `b\n` |
| 第三次 | `b` | 98 | `\n` |

程序自身输出（不包括终端回显）：

```text
a
b
97 10 98
```

> [!warning] EOF 与 char
> `EOF` 是 `<stdio.h>` 中的负整数常量表达式，类型为 `int`，常见实现为 -1，并非标准要求必须是 -1，也不是输入流中存储的一个字符。
> 
> 应使用 `int ch` 保存 `getchar()` 返回值。如果先转换为 `char` 再判断 `EOF`，可能将有效字节和结束标志混淆，也可能无法识别 EOF。

推荐写法（读取到 EOF 为止）：

```c
int ch;
while ((ch = getchar()) != EOF) {
    putchar(ch);
}
```

注意括号：`while (ch = getchar() != EOF)` 实际相当于 `ch = (getchar() != EOF)`，ch 只会得到 0 或 1。

`getchar()` 遇到 EOF 返回值也可能代表读取错误；完整程序可用 `feof(stdin)`、`ferror(stdin)` 区分（留待文件读写章节）。

## 3. 字符输出：putchar

```c
int putchar(int c);
```

将参数转换为 `unsigned char` 后写入 `stdout`；成功返回写出的字符值，失败返回 `EOF`。

课件第 8 页例题（假设 ASCII）：

```c
char c = 'a';
putchar(c);
putchar('a');
putchar(97);
putchar('\141');
```

输出 `aaaa`。八进制 `141` 等于十进制 97。

> [!warning] 注意
> `putchar(65)` 输出字符 A（ASCII），`printf("%d", 65)` 输出字符序列 `65`。`putchar('\n')` 输出换行而非两个字符 `\` 和 `n`。

## 4. printf 格式化输出

### 4.1 原型和返回值

```c
int printf(const char *format, ...);
```

格式字符串由普通字符和转换说明组成；普通字符直接输出。正常返回已输出的字符数（窄字符输出按字节计），发生输出或编码错误时返回负值。

```c
int n = printf("x=%d,y=%d\n", 314, 27);
// 输出 x=314,y=27 加换行，n = 11
```

`%%` 输出一个百分号，不消耗对应实参；`\n` 是一个换行字符。

### 4.2 常用转换说明

| 转换说明 | 要求的参数（普通形式） | 用途 |
|---|---|---|
| `%d` / `%i` | int | 有符号十进制 |
| `%u` | unsigned int | 无符号十进制 |
| `%o` | unsigned int | 无符号八进制 |
| `%x` / `%X` | unsigned int | 无符号十六进制（小写/大写） |
| `%c` | int | 单字符，转换为 unsigned char |
| `%s` | 指向字符数组首元素的指针 | 字符串 |
| `%f` / `%F` | double | 定点形式，默认小数 6 位 |
| `%e` / `%E` | double | 科学计数法，默认小数 6 位 |
| `%g` / `%G` | double | 选择定点/指数风格，默认 6 个有效数字 |
| `%p` | void * | 指针，格式由实现决定 |
| `%%` | 无 | 百分号 |
| `%n` | int * | 写入截至此处已输出的字符数，本身不输出 |

> [!note] 默认实参提升（第 07 篇）
> `printf` 的可变参数中，`float` 自动转换为 `double`，窄整数执行整数提升。因此 `%f` 接收的是 `double`，不是 `float`；`%c` 接收 `int`。格式不是用于自动将任意传入类型转换成所需类型的指令，参数类型必须正确。
> 
> ISO C99 起 `printf("%lf", d)` 与 `%f` 等效。`%Lf` 才是 long double。`printf("%p", (void *)&x)` 是可移植的地址输出方式。

### 4.3 长度修饰符

| 类型 | printf（常用） |
|---|---|
| short / unsigned short | `%hd` / `%hu` |
| signed char / unsigned char | `%hhd` / `%hhu` |
| long / unsigned long | `%ld` / `%lu` |
| long long / unsigned long long | `%lld` / `%llu` |
| size_t | `%zu` |
| float、double | `%f`（float 经提升） |
| long double | `%Lf` |

`h`、`hh` 对整数输出而言要求匹配相应的提升后参数，随后按短整数类型转换输出。`ll`、`hh`、`z` 是 C99 新增的长度修饰符。

### 4.4 标志、最小域宽、精度

完整基本形式：`%[标志][最小域宽][.精度][长度修饰符]转换字符`。

| 标志 | 意义 |
|---|---|
| `-` | 左对齐，默认右对齐 |
| `+` | 有符号数的正数也显示 `+` |
| 空格 | 有符号非负数前加一个空格；有 `+` 时忽略 |
| `0` | 数值输出用零填充；有 `-` 时忽略；整数指定精度时忽略 |
| `#` | 替代形式，非零十六进制加 0x/0X、八进制保证首位为 0；浮点保留小数点，%g 不删末尾零 |

- 域宽是**最小**输出宽度，不够时扩展，不截断；符号、小数点、指数、前缀均计入总宽度。
- `%f`、`%e`：精度为小数点后位数（输出舍入，不改变变量）。
- `%g`：精度为有效数字数，规则与指数范围相关（不是简单选择最短字符串）。
- 整数：精度为最少数字位数，必要时前补零；**整数精度为 0 且值为 0 时通常不输出数字**（`%#.0o` 例外）。
- `%s`：精度限制最多输出字节数，域宽仍是最小宽度。
- `*` 读取一个 `int` 实参作为宽度或精度。负宽度等效左对齐加正宽度，负精度视为未指定。

课件第 10 页例题（常见 IEEE 浮点环境）：

```c
int i = 15;
float x = -8.2f;
printf("i=%d, x=%8.3f\n", i, x);
```

输出 `i=15, x=  -8.200`，其中 `-8.200` 长 6，故域宽 8 补 2 个空格。

### 4.5 输出格式专项表

以下以 `·` 表示一个空格，竖线仅标示边界，不是程序的输出。

| 表达式（省略 printf） | 输出边界内的结果 |
|---|---|
| `("%5d", 123)` | `··123` |
| `("%-5d", 123)` | `123··` |
| `("%05d", -12)` | `-0012` |
| `("%+5d", 12)` | `··+12` |
| `("%5.3d", 12)` | `··012` |
| `("%2d", 12345)` | `12345` |
| `("%08.3d", 12)` | `·····012` |
| `("%#06x", 42u)` | `0x002a` |
| `("%.0d", 0)` | 空串 |
| `("%8.2f", 3.125)` | `····3.12`（近偶舍入环境） |
| `("%8.2f", 3.15625)` | `····3.16` |
| `("%6.3s", "hello")` | `···hel` |
| `("%-6.3s", "hello")` | `hel···` |
| `("%*.*f", 8, 2, 1.25)` | `····1.25` |

> [!warning] 舍入与截断
> `printf("%.2f", x)` 不改变 x，也不等同于 `(int)x`。二进制浮点的实际值可能不完全等于所写十进制数，边界舍入不能简单按课件的“四舍五入”机械判定。

## 5. scanf 格式化输入

### 5.1 原型与读、转、写机制

```c
int scanf(const char *format, ...);
```

课件第 19 页将其概括为三步：

1. 读：按格式从输入流中匹配字符序列。
2. 转：将匹配的字符序列转换为指定数据类型的值。
3. 写：将值写到实参所指向的对象中。

```c
int x;
float y;
scanf("%d%f", &x, &y);
```

`&x`、`&y` 提供接收对象的地址。若读入 `314 3.14\n`，则 x=314、y≈3.14，数字转换之间的空格被跳过，末尾换行仍留在流中。

> [!important] 返回值
> 返回成功匹配且完成赋值的输入项数（%n 除外）。如果发生匹配失败，返回已赋值的项数，可能为 0；若在首次转换完成之前发生输入失败（EOF 或读取错误），返回 EOF。已经成功赋值的对象不会因为后续失败而恢复原值。

### 5.2 常用转换说明与目标类型

| 转换说明 | 目标参数类型 | 读取规则 |
|---|---|---|
| `%d` | int * | 十进制整数 |
| `%i` | int * | 依据前缀判断进制：0x、0 或普通十进制 |
| `%u` | unsigned int * | 无符号十进制整数（语法允许符号） |
| `%o` | unsigned int * | 八进制整数 |
| `%x` / `%X` | unsigned int * | 十六进制整数 |
| `%c` | char * | 默认恰好一个字符，不跳过空白，不追加 '\0' |
| `%s` | char * | 非空白字符序列，跳过前导空白，自动追加 '\0' |
| `%f` / `%e` / `%g` | float * | 浮点数 |
| `%lf` / `%le` / `%lg` | double * | 双精度浮点数 |
| `%Lf` | long double * | 长双精度浮点数 |
| `%p` | void ** | 读取实现规定的指针形式 |
| `%n` | int * | 写入已消费字符数，不消费输入，不增加返回值 |
| `%%` | 无 | 匹配百分号 |

- `%hd` / `%hu`：short * / unsigned short *。
- `%ld` / `%lu`：long * / unsigned long *。
- `%lld` / `%llu`：long long * / unsigned long long *。
- `%hhd` / `%hhu`：signed char * / unsigned char *。
- `%zu`：size_t *。

> [!warning] printf 与 scanf 的浮点格式是必考易错点
> `printf("%f", f)` 可以输出 float 和 double（float 默认提升）；但 `scanf("%f", &f)` 只能接收 float *，`scanf("%lf", &d)` 只能接收 double *。指针不会因为可变参数自动转换为所需指针类型。

### 5.3 格式串的三类指令

| 指令类别 | 规则 |
|---|---|
| 转换说明 | 按类型匹配并转换输入 |
| 普通非空白字符 | 必须与输入中的对应字符匹配 |
| 空白字符（空格、\n、\t 等） | 消费零个或多个连续输入空白，直至非空白或输入失败 |

`%c`、`%[`、`%n` 不自动跳过前导空白；常用数值转换和 `%s` 会跳过。

```c
scanf("%d,%d", &a, &b);
```

| 输入 | 结果 |
|---|---|
| `12,34` | 两项成功 |
| `12, 34` | 两项成功，第二个 %d 跳过空格 |
| `12 ,34` | 第一项成功，普通逗号匹配失败 |
| `12 34` | 第一项成功，普通逗号匹配失败 |

若格式为 `"%d , %d"`，逗号两侧均允许零个或多个空白。

> [!warning] 格式串末尾的换行
> `scanf("%d\n", &x)` 中 `\n` 不是要求恰好一个换行，而是匹配连续空白。在交互终端中可能一直等待直到后续出现非空白字符或 EOF。

### 5.4 输入域宽与赋值抑制

形式：`%[*][最大域宽][长度修饰符]转换字符`。

- `*`：匹配并消费字段，但不写入对象，不需要对应指针，不计入返回值。
- 正整数宽度限制转换最多消费多少字符，前导自动跳过的空白不计入域宽。
- `%c` 指定宽度时要求读取相应数量的字符；`%s` 最大宽度不含自动附加的 NUL。

```c
int a, b;
scanf("%2d%3d", &a, &b); // 输入 12345 → a=12,b=345
scanf("%d%*c%d", &a, &b); // 输入 12,34 → a=12,b=34，返回2
```

```c
char buf[10];
scanf("%9s", buf); // 最多9字节，再追加 '\0'
```

> [!warning] 域宽不能用来保证整数值不溢出
> `%3d` 限制字符数，并不直接验证目标类型值域；如果转换结果无法由目标对象表示，ISO C11/C17 的 scanf 规则规定行为未定义。对不可信的复杂数值输入，可采用 `fgets` 加 `strtol` 等方式（拓展，后续文件章节再展开）。

## 6. 输入流逐字符分析（课件重点）

### 6.1 数值后读取字符：例题，第17页

```c
double x = 0.0;
char c = '\0';
scanf("%lf", &x);
scanf("%c", &c);
```

输入 `12.25\na\n` 时，第一句读取 12.25，第二句读到 `\n`，而不是 a。如果输入 `12.25 a\n`，第二句读到空格。

| 方案 | 行为 |
|---|---|
| `scanf("%lf%*c", &x); scanf("%c", &c);` | 课件方法：额外消费一个字符 |
| `scanf("%lf", &x); getchar(); scanf("%c", &c);` | 课件方法：额外消费一个字符 |
| `scanf("%lf %c", &x, &c);` | 补充方法：跳过连续空白，读取首个非空白字符 |

若输入两个空格再加 a，前两种方法仍会读到空格。第三种只适用于确实想跳过空白的情形；如果空格本身就是所需字符，应该保留 `%c` 原样。

### 6.2 课件第18页三个例题

例 A：`scanf("%c%c", &c1, &c2)`，输入 `a\n` → `c1='a'`、`c2='\n'`，返回2。

例 B：`scanf("%d%s", &x, cc)`，输入 `+1.7 HUST\n`：

| 阶段 | 消费字符 | 结果 | 剩余输入 |
|---|---|---|---|
| `%d` | `+1` | x=1 | `.7 HUST\n` |
| `%s` | `.7` | cc=".7" | ` HUST\n` |

返回2。`%d` 不会先读取整个 1.7 再截断；它只匹配合法的整数字符序列。

例 C：`scanf("%lf%s", &x, cc)`，输入 `+1.7 HUST\n` → `x≈1.7`、`cc="HUST"`，返回2，剩余换行。

如果只有 `+1.7\n`：交互终端中 `%s` 会继续等待后续非空白输入；若输入文件直接结束，返回1，cc 不发生赋值。课件结果中的破折号不能理解为自动赋空串。

### 6.3 `%d` 和 `%i` 的区别

```c
int x, y;
scanf("%d%i", &x, &y);
```

输入 `010 010`，x=10，y=8。`printf("%i", y)` 则仍然输出十进制 8。

## 7. 错误分析：格式类型、内存与安全

课件第 16 页展示了以下错误（仅用于分析，不要执行）：

```c
float x = 0;
double y = 0;
scanf("%f", &y);   // 错误：double * 传给 %f
scanf("%lf", &x);  // 错误：float * 传给 %lf
```

常见 Linux 环境下，float 占4字节，double 占8字节。错用格式可能导致仅写对象的一部分，或向对象边界之外写入。课件展示的特定运行结果只是特定环境的现象，不是标准确定的输出。

同理（课件第19、21页）：

```c
short count;
scanf("%d", &count); // 错误：%d 需要 int *
unsigned short k;
scanf("%hd", &k);    // 错误：%hd 需要 short *，应使用 %hu
int x;
scanf("%d", x);      // 错误：没有传入地址，且 x 未初始化
```

> [!danger] 未定义行为
> 格式说明与对象类型不匹配、缓冲区不足、数值无法由接收对象表示等情况可能导致 UB。不能凭课件显示的内存地址布局推出固定结果，也不能认为“运行成功”就证明代码正确。

字符串数组是常见的不同情况：`char s[20]; scanf("%19s", s);`，数组表达式通常转换为首元素指针，不应传 `&s`（它是数组指针，类型不同）。详见 [[16 一维数组、二维数组与数组算法]]、[[17 字符数组、字符串与字符串函数]]。

## 8. 返回值、输入失败与循环输入

假设 `a=10, b=20`，执行 `scanf("%d%d", &a, &b)`：

| 输入（文件直到 EOF） | 返回值 | a | b |
|---|---:|---:|---:|
| `1 2` | 2 | 1 | 2 |
| `1 x` | 1 | 1 | 20 |
| `x 2` | 0 | 10 | 20 |
| `1` | 1 | 1 | 20 |
| 空文件 | EOF | 10 | 20 |

`scanf("%d", &x)` 遇到 `abc` 返回 0，并且 a 通常仍留在流中。再次调用相同转换会继续失败。

课件第21页写法：

```c
while (scanf("%d", &n) != EOF) {
    /* 处理 n */
}
```

如果题目保证所有输入都是合法且可表示的整数，这种方式可用。更通用的写法：

```c
while (scanf("%d", &n) == 1) {
    /* 处理 n */
}
```

这保证只有成功读取整数才处理，遇到不匹配输入会停止；如果需要恢复并继续读取，必须额外消费错误输入或按行解析。

> [!warning] EOF 不是一个字符
> 不应使用 `while (!feof(stdin))` 预测下一次读取成功与否；EOF 标志是在读取遇到文件结束后设置的。`fflush(stdin)` 也不是 ISO C 定义的清空输入流方法。Linux 终端的 Ctrl-D 则是规范模式下触发读结束的控制操作，不等于向流发送一个 EOF 字符。

## 9. printf 与 scanf 对照速查

| 项目 | printf | scanf |
|---|---|---|
| 处理方向 | 值→字符 | 字符→值 |
| 普通常用参数 | 数值或字符串指针 | 对象地址 |
| 宽度 | 最小输出宽度 | 最大输入宽度（%c 要求相应数量） |
| `*` | 从实参获取宽度/精度 | 赋值抑制 |
| float | `%f`（提升为 double） | `%f`（float *） |
| double | `%f` / `%lf` (C99+) | `%lf`（double *） |
| long double | `%Lf` | `%Lf` |
| `%d` / `%i` | 都为十进制 | `%i` 自动判进制 |
| `%n` | 记录已经输出的字符数 | 记录已经消费的字符数，不计成功项数 |
| 返回值 | 输出字符数，失败负值 | 成功赋值项数或 EOF |

## 10. VMC 在线评测与 Linux 实践

课件第20–21页强调：评测平台使用预先准备的测试输入，程序不应输出题目未要求的提示；不依赖手动按 Enter；仔细核对输出格式。本地 IDE 能运行不表示不存在 UB。未初始化的自动局部变量也不能假定为 0。

使用 Linux 标准流重定向测试：

```bash
printf '12.25\na\n' | ./demo
./demo < input.txt > output.txt
diff -u expected.txt output.txt
```

可验证的 C11/C17 示例（`demo.c`）：

```c
#include <stdio.h>

int main(void)
{
    int x = 0, n = 0;
    char word[16];
    int r = scanf("%d%15s%n", &x, word, &n);
    if (r != 2)
        return 1;
    int next = getchar();
    printf("x=%d word=[%s] consumed=%d\n", x, word, n);
    printf("next=%d\n", next);
    printf("[%05d][%-6.3s][%*.*f]\n", -12, "hello", 8, 2, 1.25);
    return 0;
}
```

```bash
gcc -std=c17 -Wall -Wextra -Wformat=2 -Wconversion -pedantic demo.c -o demo
printf '+1.7 HUST\n' | ./demo
```

预期（ASCII Linux）：

```text
x=1 word=[.7] consumed=4
next=32
[-0012][hel   ][    1.25]
```

`%n` 本身不计入 scanf 返回值；下一字符为空格。注意在实际程序中格式串最好是受信任的字面量，例如输出用户字符串应写 `printf("%s", user_input)`，而不是让用户内容直接成为格式串（格式字符串漏洞，安全拓展）。

## 11. 笔试解题方法与课件辨析

### 输出题

1. 根据类型和默认实参提升确定参数是否匹配。
2. 先确定输出的实际内容（进制、符号、精度、前缀）。
3. 按最小域宽计算填充，注意标志之间的覆盖关系。
4. 统计普通字符、空格、换行等；不要计入终端回显。

### 输入题

1. 把输入写成字符序列，明确空格、换行和 EOF 所在位置。
2. 从左往右逐项处理格式串，先确定是否跳过空白。
3. 确定匹配长度、转换目标类型及写入对象。
4. 标出未消费字符和成功赋值次数；匹配失败立即停止。
5. 检查接收对象类型、容量和转换范围；有 UB 时不求确定结果。

| 课件位置 | 标准辨析 |
|---|---|
| 第6页 EOF 值为-1、字符 ASCII 值 | 常见实现；标准只要求 EOF 为负 int，返回值依据实际字符编码 |
| 第11页 printf 的 float/char 参数 | 可变实参 float 提升 double，char 发生整数提升；%c 接收 int |
| 第11页 %o/%x/%u 参数 | 对应无符号整数类型，不宜一概写为 int |
| 第11页 %s 通过域宽限长 | 输出限制使用精度（例如 %.3s），普通域宽不会截断 |
| 第13页 scanf 遇到 EOF 返回 EOF | 必须区分首次转换前的输入失败与已有成功赋值的情况 |
| 第14页 %c 可以接收 int 变量地址 | 普通 %c 应接收 char *；%1s 需要至少2字节，不宜直接传单独 char 的地址 |
| 第14页 scanf %p 参数为 void * | 实际要求 void ** |
| 第15页 L 用于双精度 | %lf 读 double，%Lf 读 long double |
| 第16页错用 %f/%lf 的具体输出 | UB，不能认为结果固定 |
| 第17页虚读一个分隔字符 | 只消费一个字符，不等于跳过任意空白 |
| 第21页 scanf(...) != EOF | 合法输入有保证时可用；一般使用 == 预期赋值数 |

## 12. 自测题（26道）

默认 ASCII、8位字节、32位 int、16位 short、C17，所有输入题如未特别说明均假设其后到达文件末尾。各题互相独立。

### 字符与输出

1. `getchar` 的返回类型是什么？EOF 是字符吗？
2. 输入 `A\nB\n`，连续两次 getchar 得到什么？
3. `putchar('\101'); printf("%d", 'A');` 输出什么？
4. `printf("%5d", 123456)` 输出什么？
5. `printf("[%05d]", -12)` 输出什么？
6. `printf("[%8.3d]", 12)` 输出什么？
7. `printf("[%08.3d]", 12)` 输出什么？
8. `printf("[%-6.3s]", "hello")` 输出什么？
9. `printf("%#06x", 42u)` 输出什么？
10. `int n=printf("A%%\n");` n 是多少？
11. `float f=1.25f; printf("%f", f);` 实际可变实参类型是什么？
12. `printf("%.2f", 3.15625)` 输出后，该浮点值是否被改变？

### 输入与综合

13. `scanf("%d%c", &x, &c)` 输入 `123\n`，x、c、返回值？
14. `scanf("%d %c", &x, &c)` 输入 `123 \n A`，结果？
15. `scanf("%d%s", &x, s)` 输入 `+1.7 HUST`，结果和剩余输入？
16. `scanf("%2d%3d", &x, &y)` 输入 `12345`，结果？
17. `scanf("%d%*c%d", &x, &y)` 输入 `12,34`，返回多少？
18. `scanf("%d%i", &x, &y)` 输入 `010 010`，结果？
19. `scanf("%d,%d", &x, &y)` 输入 `12 ,34`，返回值和剩余输入？
20. `char s[10]; scanf("%9s", s);` 输入 `abcdefghijk`，s 和剩余输入？
21. `char s[3]; scanf("%3c", s);` 输入 `abc`，s 是否是 C 字符串？
22. `scanf("%d%d", &x, &y)` 输入 `1 x`，返回多少？
23. `scanf("%d", &x)` 输入 `abc`，返回多少？是否消耗 a？
24. `scanf("%d%d", &x, &y)` 输入文件仅有 `1`，返回多少？
25. `printf("%f", 3);`、`scanf("%f", &d);`（double d）是否正确？
26. `scanf("%d%n", &x, &n)` 输入 `  123x`，x、n、返回值和剩余字符？

> [!success]- 答案与解析（展开自测）
> 1. int；EOF 是负整数标志，不是流中的字符。
> 2. `'A'` 和 `'\n'`。
> 3. `A65`，八进制 101 为 65。
> 4. `123456`，域宽不足时扩展。
> 5. `[-0012]`，零填充在负号之后。
> 6. `[     012]`，5个空格。
> 7. `[     012]`，整数有精度时忽略0标志。
> 8. `[hel   ]`，三个尾部空格。
> 9. `0x002a`，前缀计入总宽度。
> 10. 3，`A`、`%`、换行。
> 11. double。
> 12. 不改变；输出 `3.16`（常见近偶舍入模式）。
> 13. x=123，c='\n'，返回2。
> 14. x=123，c='A'，返回2。
> 15. x=1，s=".7"，剩余 ` HUST`，返回2。
> 16. x=12，y=345，返回2。
> 17. 2，虚读的字符不算赋值。
> 18. x=10，y=8。
> 19. 返回1，剩余 ` ,34`，逗号匹配失败。
> 20. s="abcdefghi"（附 NUL），剩余 `jk`。
> 21. 否：没有自动附加 NUL；三个元素均非零。
> 22. 1，y 不赋值，x=1。
> 23. 0，a 仍未消费。
> 24. 1，不是 EOF，因为已完成一次转换。
> 25. 均错误，类型不匹配导致 UB。正确为 `printf("%f", 3.0)` 和 `scanf("%lf", &d)`。
> 26. x=123，n=5（含两个前导空格），返回1，剩余 `x`；%n 不增加赋值计数。
