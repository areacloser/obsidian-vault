# 微积分A 第一课：课程导论、实数与函数

## 1. 课程框架与学习要求

### 1.1 微积分A = 微分学 + 积分学

- **微分学**：以 [[极限论]] 为基础，把“无限接近”严格化。数列极限用 [[ε-N语言]]，函数极限用 [[ε-δ语言]]。
- **积分学**：先学不定积分、定积分；真正积分理论从 [[黎曼积分]] 开始。大学初学阶段主要学黎曼积分，后续还有 [[斯蒂尔切斯积分]] 等。定积分是核心。
- **常微分方程 ODE**：只讲简单类型求解，不展开。ODE = Ordinary Differential Equation。
- **下学期**：[[级数理论]]、[[多元微积分]]。级数可转化为部分和数列，用数列极限定义收敛。

> [!important] 核心
> 极限论是整个微积分的基础。下学期级数、多元微积分中的很多定义，都是一元分析学中极限语言的推广。

## 2. 实数

### 2.1 实数系

- 实数集：$\mathbb{R}$
- 有理数集：$\mathbb{Q}$
- 整数集：$\mathbb{Z}$
- 正整数集：$\mathbb{N}$

有理数：
$$q=\frac{p}{q},\quad p,q\in\mathbb{Z},\ q\ne0$$
也可表示为有限小数或无限循环小数。

无理数：无限不循环小数。

### 2.2 实数六大性质

1. **封闭性 / 域性**  
   $\mathbb{R}$ 对加、减、乘、除（除数非零）封闭，构成一个域。

2. **传递性**  
   若 $a>b,\ b>c$，则 $a>c$。

3. **有序性**  
   任意 $a,b\in\mathbb{R}$，$a>b$、$a<b$、$a=b$ 三者恰有一成立。

4. **阿基米德性**  
   $$\forall a>0,\ b>0,\ \exists n\in\mathbb{N},\quad na>b$$

5. **稠密性**  
   任意 $a<b$，存在 $c\in(a,b)$；$c$ 可为有理数或无理数。  
   任意小区间内都有无穷多个有理数和无理数。

6. **完备性**  
   实数与数轴上的点一一对应，数轴“没有间隙”。  
   这是微积分理论最底层的基础。等价刻画包括：
   - [[确界原理]]
   - 单调有界定理
   - 闭区间套定理
   - 有限覆盖定理
   - 聚点定理
   - 柯西收敛准则

> [!important] 完备性为何重要
> 讨论 $\lim_{x\to a}f(x)$ 前，要保证 $x$ 能连续地趋向 $a$，且函数在附近有定义。实数完备性保证极限过程有坚实基础。

### 2.3 ε 方法例子

若对任意 $\varepsilon>0$，都有
$$a<b+\varepsilon$$
则
$$a\le b$$

证明（反证）：  
若 $a>b$，取 $\varepsilon_0=a-b>0$，则
$$b+\varepsilon_0=a$$
与 $a<b+\varepsilon_0$ 矛盾。故 $a\le b$。$\square$

用途：证明不等式、极限、估计时常用。

## 3. 常用不等式

> [!tip] 这些不等式是极限证明和放缩估计的核心工具。

1. **三角不等式**
$$||a|-|b||\le |a\pm b|\le |a|+|b|$$

2. **[[伯努利不等式]]**
$$(1+x)^n\ge 1+nx,\quad x>-1,\ n\in\mathbb{N},\ n\ge1$$

3. **柯西不等式**
$$\left(\sum_{i=1}^n x_i y_i\right)^2\le \left(\sum_{i=1}^n x_i^2\right)\left(\sum_{i=1}^n y_i^2\right)$$
向量形式：
$$|\vec{x}\cdot\vec{y}|\le \|\vec{x}\|\,\|\vec{y}\|$$
可向无穷维、一般内积空间推广。

4. **Hölder 不等式**  
   设 $p,q>1$，$\frac1p+\frac1q=1$，
$$\sum_{i=1}^n |x_i y_i|\le \left(\sum_{i=1}^n |x_i|^p\right)^{1/p}\left(\sum_{i=1}^n |y_i|^q\right)^{1/q}$$
$p=q=2$ 时退化为柯西不等式。

5. **Young 不等式**  
   $a,b\ge0$，$p,q>1$，$\frac1p+\frac1q=1$，
$$ab\le \frac{a^p}{p}+\frac{b^q}{q}$$
常用带 $\varepsilon$ 形式：
$$ab\le \varepsilon a^p+C(\varepsilon)b^q$$
用于“吸收”不想要的项。

> [!note] 不等式在后续课程中
> 极限的 $\varepsilon$ 证明、偏微分方程估计等，本质都是放缩和不等式技巧。放得太大或太小都得不出结论。

## 4. 区间、邻域与符号

### 4.1 区间

- 开区间：$(a,b)=\{x:a<x<b\}$
- 闭区间：$[a,b]=\{x:a\le x\le b\}$
- 半开半闭：$[a,b)$、$(a,b]$
- 无穷区间：$(-\infty,a)$、$(b,+\infty)$、$\mathbb{R}=(-\infty,+\infty)$

### 4.2 邻域

- 点 $a$ 的 $\delta$ 邻域：
$$U(a,\delta)=\{x\in\mathbb{R}: |x-a|<\delta\}=(a-\delta,a+\delta)$$

- 去心邻域：
$$U^\circ(a,\delta)=\{x:0<|x-a|<\delta\}$$

- 左邻域：
$$U_-(a,\delta)=\{x:a-\delta<x\le a\}$$

- 右邻域：
$$U_+(a,\delta)=\{x:a\le x<a+\delta\}$$

- 去心左/右邻域：把等号去掉。

### 4.3 常用符号

| 符号 | 含义 |
|---|---|
| $\in$ | 属于 |
| $\forall$ | 任意 |
| $\exists$ | 存在 |
| $\mathbb{N}$ | 正整数集 |
| $\mathbb{Z}$ | 整数集 |
| $\mathbb{Q}$ | 有理数集 |
| $\mathbb{R}$ | 实数集 |
| $\square$ 或 # | 证明结束 |

## 5. 有界集与确界原理预告

### 5.1 有界集

设 $S\subset\mathbb{R}$ 非空。

- **有界**：存在 $m,n\in\mathbb{R}$，使
$$\forall x\in S,\quad m\le x\le n$$
等价地，存在 $M>0$，使
$$\forall x\in S,\quad |x|\le M$$
几何上：$S$ 可被某个有限区间包含。

- **有上界**：存在 $M$，$\forall x\in S,\ x\le M$。
- **有下界**：存在 $m$，$\forall x\in S,\ x\ge m$。

### 5.2 下节课预告

路线：
[[有界集]] → [[确界]]（上确界/下确界） → [[确界原理]]

确界原理是实数完备性的重要等价定理之一，也是高等数学中较难理解但极重要的结论。之后讲函数基本概念。
