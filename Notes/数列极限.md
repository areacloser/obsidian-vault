# 微积分数列极限定义及收敛数列基本性质

> **课程时间**：2026-10-09
> **内容来源**：课堂录音转写（已修正）+ 手写笔记整理
> **核心目标**：理解数列极限的严格 $\varepsilon-N$ 定义，掌握用定义证明极限的方法，理解收敛数列的基本性质（唯一性、有界性、保号性与比较定理）。

---

## 一、 数列极限的严格定义 ($\varepsilon-N$ 语言)

### 1. 定义引入
之前我们通过“无限接近”来直观理解数列极限，例如数列 $a_n = \frac{1}{n}$，当 $n$ 不断增大时，$a_n$ 与 $0$ 无限接近。为了将这种“无限接近”精确化，我们引入严格的数学语言。

**定义**：设 $\{a_n\}$ 为一个数列，$a$ 为一个实数。如果对任给的正数 $\varepsilon > 0$，总存在正整数 $N$，使得当 $n > N$ 时，都有：
$$|a_n - a| < \varepsilon$$
则称数列 $\{a_n\}$ 收敛于 $a$，记为 $\lim_{n \to \infty} a_n = a$。

### 2. 定义的理解与注记
*   **$\varepsilon$ 的作用**：$\varepsilon$ 是任意给定的、非常小的正数，代表我们要求的“接近程度”。
*   **$N$ 的存在性与依赖性**：
    *   $N$ 是一个正整数，且必须明确给出。
    *   $N$ 通常依赖于 $\varepsilon$，记作 $N(\varepsilon)$。通常 $\varepsilon$ 越小，要求的 $N$ 越大。
    *   只要给出了一个满足条件的 $N$ 即可，哪怕形式很复杂。
*   **前有限项无关性**：修改或删除数列的前有限项，不影响数列的收敛性及其极限值。因为极限刻画的是数列在无穷远处的趋势。
*   **几何直观**：
    *   **数轴视角**：$|a_n - a| < \varepsilon \iff a_n \in (a-\varepsilon, a+\varepsilon)$。即当 $n > N$ 时，所有的点 $a_n$ 都落在以 $a$ 为中心、$\varepsilon$ 为半径的邻域内。前面的有限项可能落在邻域外，但并不影响整体趋势。
    *   **函数视角**：将数列看作函数 $a_n = f(n)$，图像上有两条水平线 $y = a + \varepsilon$ 和 $y = a - \varepsilon$。当 $n > N$ 时，所有的点 $(n, a_n)$ 都落在两条线构成的“带宽”（管道）内，且随着 $n$ 增大逐渐向中间 $y=a$ 靠拢。

## 二、 用定义证明数列极限（典型例题）

### 例题 1：直接解不等式
**证明**：$\lim_{n \to \infty} \frac{1}{n^\alpha} = 0 \quad (\alpha > 0)$
**分析**：
对任给的 $\varepsilon > 0$，要使 $|\frac{1}{n^\alpha} - 0| < \varepsilon$，即 $\frac{1}{n^\alpha} < \varepsilon$。
两边变形得 $n^\alpha > \frac{1}{\varepsilon}$，解得 $n > \left(\frac{1}{\varepsilon}\right)^{\frac{1}{\alpha}}$。
**证明过程**：
$\forall \varepsilon > 0$，取 $N = \left[ \left(\frac{1}{\varepsilon}\right)^{\frac{1}{\alpha}} \right] + 1$（取整加一以保证正整数）。
则当 $n > N$ 时，有 $n > \left(\frac{1}{\varepsilon}\right)^{\frac{1}{\alpha}}$，从而 $\frac{1}{n^\alpha} < \varepsilon$，即 $|\frac{1}{n^\alpha} - 0| < \varepsilon$。
故 $\lim_{n \to \infty} \frac{1}{n^\alpha} = 0$。

### 例题 2：适当放缩法（简化不等式）
**证明**：$\lim_{n \to \infty} \frac{3n^2}{n^2 - 3} = 3$
**分析**：
直接解不等式可能较复杂（二次函数），此时可先对表达式进行适当放大。
$$\left| \frac{3n^2}{n^2 - 3} - 3 \right| = \left| \frac{9}{n^2 - 3} \right|$$
限定 $n > 2$，则 $n^2 - 3 > 0$，去绝对值。进一步通过放缩使其更容易求解：
$$\frac{9}{n^2 - 3} = \frac{9}{(n-\sqrt{3})(n+\sqrt{3})} < \frac{9}{n - \sqrt{3}}$$
要使原式小于 $\varepsilon$，只需 $\frac{9}{n - \sqrt{3}} < \varepsilon$ 即可（因为原式小于这个放缩后的式子，放缩式小于 $\varepsilon$ 推出原式小于 $\varepsilon$）。
解 $\frac{9}{n - \sqrt{3}} < \varepsilon$ 得 $n > \frac{9}{\varepsilon} + \sqrt{3}$。
**证明过程**：
$\forall \varepsilon > 0$，取 $N = \left[ \frac{9}{\varepsilon} + \sqrt{3} \right] + 1$。
当 $n > N$ 时，$n > 2$，有：
$$\left| \frac{3n^2}{n^2 - 3} - 3 \right| = \frac{9}{n^2 - 3} < \frac{9}{n - \sqrt{3}} < \varepsilon$$
故 $\lim_{n \to \infty} \frac{3n^2}{n^2 - 3} = 3$。

### 例题 3：复杂放缩与二项式定理
**证明**：$\lim_{n \to \infty} \frac{\ln n}{n} = 0$
**分析**：
要证 $\forall \varepsilon > 0, |\frac{\ln n}{n} - 0| < \varepsilon \iff \ln n < n\varepsilon \iff n < e^{n\varepsilon} \iff n^{\frac{1}{n}} < e^\varepsilon$。
这转化为寻找 $N$，使得当 $n > N$ 时，$n^{\frac{1}{n}} < e^\varepsilon$。
利用技巧，设 $n^{\frac{1}{n}} = 1 + \lambda_n \ (\lambda_n \ge 0)$。
由二项式定理：$n = (1+\lambda_n)^n = 1 + n\lambda_n + \frac{n(n-1)}{2}\lambda_n^2 + \dots > \frac{n(n-1)}{2}\lambda_n^2$。
所以 $\lambda_n^2 < \frac{2}{n-1}$，即 $\lambda_n < \sqrt{\frac{2}{n-1}}$。
从而 $n^{\frac{1}{n}} = 1 + \lambda_n < 1 + \sqrt{\frac{2}{n-1}}$。
要使 $n^{\frac{1}{n}} < e^\varepsilon$，只需 $1 + \sqrt{\frac{2}{n-1}} < e^\varepsilon$，解得 $n > \frac{2}{(e^\varepsilon - 1)^2} + 1$。
**证明过程**：
$\forall \varepsilon > 0$，取 $N = \left[ \frac{2}{(e^\varepsilon - 1)^2} \right] + 1$。
当 $n > N$ 时，有 $n^{\frac{1}{n}} < e^\varepsilon$，取对数得 $\frac{\ln n}{n} < \varepsilon$。
故 $\lim_{n \to \infty} \frac{\ln n}{n} = 0$。

> **方法总结（放缩法）**：若直接求解 $|a_n - a| < \varepsilon$ 困难，可适当放大 $|a_n - a| \le g(n)$，令 $g(n) < \varepsilon$ 求解 $n > \varphi(\varepsilon)$，然后取 $N = [\varphi(\varepsilon)] + 1$。

## 三、 数列发散的定义

数列收敛定义的否定：
若 $\exists \varepsilon_0 > 0, \forall N \in \mathbb{N}^*, \exists n > N$，使得 $|a_n - a| \ge \varepsilon_0$，则称数列 $\{a_n\}$ 不收敛于 $a$。
若数列 $\{a_n\}$ 不以任何实数为极限，则称其为**发散数列**。
**典型例子**：$(-1)^n = -1, 1, -1, 1, \dots$ 在 $-1$ 和 $1$ 之间跳跃，发散。

## 四、 收敛数列的基本性质

### 1. 性质一：极限的唯一性
**定理**：若数列 $\{a_n\}$ 收敛，则其极限唯一。
**证明（反证法）**：
假设数列收敛于两个不同的极限 $a$ 和 $b$，且 $a < b$。
取 $\varepsilon = \frac{b-a}{2} > 0$。
因为 $a_n \to a$，$\exists N_1 \in \mathbb{N}^*$，当 $n > N_1$ 时，$|a_n - a| < \frac{b-a}{2} \implies a_n < a + \frac{b-a}{2} = \frac{a+b}{2}$。
因为 $a_n \to b$，$\exists N_2 \in \mathbb{N}^*$，当 $n > N_2$ 时，$|a_n - b| < \frac{b-a}{2} \implies a_n > b - \frac{b-a}{2} = \frac{a+b}{2}$。
取 $N = \max\{N_1, N_2\}$，当 $n > N$ 时，同时有 $a_n < \frac{a+b}{2}$ 和 $a_n > \frac{a+b}{2}$，矛盾。
故 $a = b$。

### 2. 性质二：收敛数列的有界性
**定理**：收敛数列必定有界。
**证明**：
设 $\lim_{n \to \infty} a_n = a$。取 $\varepsilon = 1$，则 $\exists N \in \mathbb{N}^*$，当 $n > N$ 时，$|a_n - a| < 1$。
从而 $|a_n| = |a_n - a + a| \le |a_n - a| + |a| < 1 + |a|$。
令 $M = \max\{|a_1|, |a_2|, \dots, |a_N|, 1 + |a|\}$，则对一切 $n \in \mathbb{N}^*$，有 $|a_n| \le M$。
即有界。
> **注记**：
> 1. 逆命题不成立。有界数列不一定收敛（例如 $(-1)^n$）。但存在收敛的子列（Bolzano-Weierstrass 定理，后续课程证明）。
> 2. 逆否命题成立：无界数列必定发散（例如 $a_n = n$）。

### 3. 性质三：比较定理与保号性
**定理（比较定理）**：设 $\lim_{n \to \infty} a_n = a$，$\lim_{n \to \infty} b_n = b$。
1. 若 $a < b$，则当 $n$ 充分大时，$a_n < b_n$。
2. 若当 $n$ 充分大时 $a_n \le b_n$，则 $a \le b$。
**证明（第一点）**：
取 $\varepsilon = \frac{b-a}{2} > 0$。
由极限定义，$\exists N_1, N_2$ 使得当 $n > N_1$ 时 $|a_n - a| < \frac{b-a}{2} \implies a_n < \frac{a+b}{2}$；
当 $n > N_2$ 时 $|b_n - b| < \frac{b-a}{2} \implies b_n > \frac{a+b}{2}$。
取 $N = \max\{N_1, N_2\}$，当 $n > N$ 时，$a_n < \frac{a+b}{2} < b_n$。
第二点可由第一点反证导出。

> **注意**：若将条件 $a_n \le b_n$ 中的“$\le$”改为严格小于“$<$”，结论 $a < b$ 不一定成立。
> 例如：$a_n = -\frac{1}{n}, b_n = \frac{1}{n}$，有 $a_n < b_n$，但 $\lim a_n = \lim b_n = 0$。

**推论（保号性）**：设 $\lim_{n \to \infty} a_n = a$。
1. 若当 $n$ 充分大时 $a_n \ge 0$，则 $a \ge 0$。
2. 若存在 $b, c \in \mathbb{R}$，使得当 $n$ 充分大时 $b \le a_n \le c$，则 $b \le a \le c$。
3. 若存在 $b, c \in \mathbb{R}$，使得 $b < a < c$，则当 $n$ 充分大时，$b < a_n < c$。
*（这些推论在后续函数极限、定积分证明中反复用到，需熟练掌握几何直观理解。）*

## 五、核心要点总结

| 概念      | 关键结论                                                |
| ------- | --------------------------------------------------- |
| 极限定义    | $\forall \varepsilon > 0, \exists N, s, t,\forall n > N, \lvert a_n - a \rvert < \varepsilon$ |
| $N$ 的特性 | 依赖于 $\varepsilon$，必须存在且可求出                          |
| 收敛数列    | 极限唯一、有界、保号、保序                                       |
| 逆命题     | 有界 $\nRightarrow$ 收敛；$a_n < b_n \nRightarrow a < b$ |
| 证明技巧    | 放缩法、反证法、三角不等式、数轴/几何直观                               |
